# 다국어 (i18n)

지금은 일본어만 지원한다. 다른 언어를 추가할 수 있는 **구조**만 갖춰 두었고, 화면은 이전과 같다.

## 지금 구조

| 무엇 | 어디 | 규칙 |
|---|---|---|
| 지원 언어 | `lib/i18n/config.ts` | `locales = ["ja"]`, 기본 언어 `ja` (URL 접두사 없음) |
| 화면 문구 | `lib/i18n/dictionaries/ja.ts` | 모든 UI 문구. `{name}` 자리는 `format()`으로 채운다. 값은 문자열만 (클라이언트에 그대로 넘김) |
| 날짜 | `formatDate()` (`lib/i18n/index.ts`) | 일본어는 `2026.10.30` |
| 콘텐츠의 번역 가능한 필드 | `lib/types.ts`의 `*Source` 타입 | `Localized`: 그냥 쓰면 일본어, 번역은 `{ ja: "…", ko: "…" }`. 번역이 없으면 일본어로 표시 |
| 콘텐츠 → 화면 문자열 | `lib/data.ts` 앞부분 | `localize()`로 언어별 문자열로 바꾼다. 페이지는 `string`만 본다 |
| 맛 키워드·안주 장르·궁합 등급·日本酒 가이드의 값 | id (`crisp`, `fried`, `aun`, `high`…) | 화면 라벨은 사전 (`tastes`, `genres`, `levels`, `sakeGuide`) |
| 사이트 내부 URL | `lib/routes.ts`의 `paths` | 기본 언어는 `/brands`, 다른 언어는 `/ko/brands` |
| 재발 방지 | `test/i18n.test.ts` | `app/`, `components/`, `lib/og.tsx`에 일본어를 직접 쓰면 실패 (주석, 「阿」「吽」 장식 글자, 개발자용 `throw new Error`는 예외) |

번역하지 않는 것: 「阿」「吽」 장식 글자(로고), 사이트 이름 `AUN`, 영문 장식 제목(FIND YOUR PAIR 등), 일본어 읽기(`kana`, 일본어 검색용).

## 언어를 추가하는 순서 (예: 한국어)

1. **설정**: `locales`에 `"ko"`, `htmlLang`·`ogLocale`에 값을 추가한다.
2. **사전**: `dictionaries/ko.ts`를 `Dictionary` 타입으로 만든다 (빠진 키는 타입 에러). `index.ts`에 등록하고 `formatDate()`에 `ko`를 추가한다.
3. **폰트**: Zen Kaku Gothic New와 Zen Antique에는 **한글 글리프가 없다**. 한국어용 본문 폰트(예: Noto Sans KR)를 `next/font`로 추가하고, `lang`별로 `font-family`를 바꾼다. OG 이미지(`lib/og.tsx`, `assets/fonts`)도 마찬가지.
4. ✅ **데이터 계층**: 조회 함수는 이미 `locale`을 받고, 언어별 저장소(`lib/data/store.ts`)를 만든다. 페이지의 `const locale = defaultLocale`만 바꾸면 된다.
5. **라우팅**: 일본어 URL은 그대로 두고 `/ko/...`를 추가한다.
   - 루트 레이아웃을 route group으로 나눈다: `app/(ja)/layout.tsx` (`<html lang="ja">`), `app/[lang]/layout.tsx` (`generateStaticParams`는 기본 언어를 뺀 언어). 페이지 본문은 공통 컴포넌트로 빼고, 두 쪽 `page.tsx`는 `locale`만 넘기는 얇은 파일로 만든다.
   - 루트 레이아웃이 여러 개가 되면 일치하지 않는 URL의 404 처리 방식이 바뀐다. 그 시점의 Next 문서(`global-not-found`)를 확인한다.
   - Proxy로 `/` → `/ja` 재작성하는 방식은 `usePathname()`의 hydration 불일치 주의 사항이 있어서(문서 `use-pathname.md`) 쓰지 않는다.
   - 각 페이지의 `const locale = defaultLocale`을 `params.lang`에서 받도록 바꾼다.
6. **SEO**: `pageMetadata()`에 `alternates.languages`(hreflang), sitemap에 언어별 URL, RSS는 언어별 피드.
7. **콘텐츠 번역**: 필요한 필드부터 `{ ja, ko }`로 추가한다. 번역이 없으면 일본어로 표시되니 한 번에 다 할 필요는 없다. 번역률을 보고 싶으면 `localize()`를 쓰는 곳에서 빠진 언어를 세는 스크립트를 만든다.
8. **검색**: `normalize()`는 NFKC와 가타카나→히라가나만 한다. 한국어 검색어(초성 등)를 지원하려면 그때 확장한다.

## 화면 문구를 추가할 때

1. `dictionaries/ja.ts`에 키를 추가한다 (언어가 늘어나 있으면 다른 언어 사전에도 — 타입 에러로 알 수 있다).
2. 컴포넌트에서 `getDictionary(locale)`로 가져온다. `locale`은 페이지에서 props로 내려준다.
3. 값이 들어가는 문구는 `"{name}に合うお酒"`처럼 쓰고 `format()`으로 채운다. 문자열을 이어 붙이지 않는다 (언어마다 어순이 다르다).
